# 1WIN GAMES — русская версия интерфейса

Самостоятельная статическая сборка по публичному образцу `minimal-magic-load.lovable.app`.

- `index.html` — главная страница и выбор режимов.
- `okoknew.html` — компактный каталог всех 14 карточек.
- `games/luckyjet.html` — интерфейс с персонажем и облаками по образцу, наш поток и модель в раскрываемом блоке.
- `games/luckyjetv12.html` — фиолетовая карточка V12 по образцу, наш поток и оценки модели.
- `games/analysis.html` — сохранённый полный анализ, история и журнал окон.
- Остальные 12 страниц — явно обозначенные локальные учебные демонстрации.

Все элементы интерфейса — по-русски; названия брендов могут сохранять оригинальное написание. Обложки взяты из публично доступного образца; источники и контрольные суммы — `docs/media-attribution.json`. Программный код этой сборки написан отдельно. Чужие авторизация, сервер подписок, платёжные формы, сессии, трекеры и утверждения о «98% точности» не включены.

LuckyJet читает только наш разрешённый публичный read-only API. Ключи и игровые сессии в клиенте отсутствуют. Порядок и полнота официальных игровых раундов не подтверждены. Сервис-воркер кэширует только статические файлы; данные API не сохраняются в его кэше. При задержке более трёх минут текущая оценка скрывается.

MTPP — экспериментальная модель, а не способ узнать будущий краш. Результаты проверки против частотной базы показаны в интерфейсе. Демо-режимы не подключены к играм букмекера и не предсказывают их результаты.

Проверка: `node --test tests/*.test.mjs`. Локальный просмотр: `node scripts/preview.mjs`.
Файлы можно публиковать целиком с относительными адресами, включая подпапку GitHub Pages. Главный код и работающие версии предыдущих сайтов не изменяются.
