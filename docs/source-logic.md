# Две версии LuckyJet: перенос клиентских правил

Публичный образец: https://minimal-magic-load.lovable.app/ — страницы `/games/luckyjet.html` и `/games/luckyjetv12.html`.

## Обычный LuckyJet

В исходнике нет сетевых запросов или анализа истории. После анимации 7–12 секунд выбираются случайно нижняя граница 2–2,35×, верхняя 3–4×, процент 96–98 и начало окна через 2 либо 3 минуты. Окно длится минуту. Кнопка блокируется на три минуты после генерации. Параметры сохраняются локально. Эти правила воспроизведены, а процент подписан демонстрационным. Проверки попаданий в исходнике нет; записи этой версии имеют статус «Без проверки в образце».

## LuckyJet V12

Кнопка создаёт случайную цель 2–2,5× и задержку 120–180 секунд; время округляется вниз до целой минуты. Процент 96–98 тоже случайный. До начала окна — ожидание, затем проверка минуты с дополнительными 45 секундами на завершение полёта. Расчёт полёта: `min(60000, log(max(coef,1)) / 0.11 * 1000)`. Попадание — оценочное начало полёта внутри минуты и коэффициент не ниже цели. Баннер результата остаётся 10 секунд. Серия коэффициентов ≥1,5 считается, но автоматическое создание сигналов в образце отключено. Эти правила сохранены.

## Подключение и отличия

Используется наш существующий публичный read-only API `/api/rounds` на `luckyjet-full-logic-v13-mpk.miuipro1993.chatgpt.site`, читающий наш Supabase. V12 обновляет историю каждые 2 секунды при активной вкладке, с защитой от параллельных запросов и задержкой повторов при ошибках. Обычная версия дополнительно показывает нашу историю с интервалом 5 секунд. Сами случайные цели от истории не зависят.

Чужие встроенные session-id/customer-id, авторизация, реклама и реферальные ссылки не перенесены. Случайный онлайн-счётчик 200–280 заменён настоящим числом загруженных записей. Случайные проценты не названы измеренной точностью. Открытая страница браузера не гарантирует работу фоновых таймеров при её закрытии; после возвращения загружается пропущенная история.

Проверка использует временную метку завершения из источника, а не время прихода пачки. Расчёт начала полёта остаётся приближением образца, а не подтверждённой меткой игры. Перед промахом проверяется доступность последовательности записей от сохранённой точки до конца окна. Если данных недостаточно, после минуты ожидания результат — «Нет данных», он исключается из доли попаданий. «Промах по истории» относится к загруженной последовательности, а не доказанной полноте игровых раундов. Повторный ответ API не создаёт второй результат.

Текущее окно V12 и журнал сохраняются локально, чтобы перезагрузка не меняла цель или время. Полный прежний анализ и его независимый журнал остаются на `games/analysis.html`.
